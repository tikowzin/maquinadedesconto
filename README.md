# Máquina de Desconto 
Um script simples em **Python** desenvolvido para calcular o valor final de um produto após a aplicação de um desconto percentual. O programa conta com validação robusta de dados para garantir que entradas incorretas não quebrem a execução.
Certifique-se de ter o [Python](https://www.python.org/) instalado em sua máquina.

1. Clone ou baixe este repositório/arquivo.
2. Abra o terminal ou prompt de comando na pasta do arquivo.
3. Execute o script com o comando:
   ```bash
   python nome_do_arquivo.py
   ```
